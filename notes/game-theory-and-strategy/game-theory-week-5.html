Part A: Repeated Games

1. What is a repeated game?

So far a game was played once. In real life people meet again and again: the same two shops compete every day, the same two countries negotiate every year. When you know you will meet someone again, your behaviour today can change. You can reward or punish them tomorrow. This is what the lecture asks:

  • What happens when players interact again and again?
  • Can cooperation survive in a Prisoner's-Dilemma-like situation?
  • What is the role of reputation and punishment?
  • We sometimes answer "tit for tat". Is that a good strategy?
Stage game (G): the one-shot game that is played over and over. Round / iteration: one play of G. Repeated game: G played several times, with the players watching and remembering what happened.

Three assumptions (from the slides):
  1. Players observe and remember the outcome of every earlier round.
  2. A player may respond differently to each possible history. (This is what makes a repeated game an extensive-form game, as the lecturer wrote on the slide.)
  3. A player's total payoff is the sum of what she earns over the rounds (for infinite games: the discounted sum, Section 4).

The loop that defines a repeated game. A strategy says what to do after every possible history.

The stage game we will use all week: the Prisoner's Dilemma

Cooperate (C) = remain silent. Defect (D) = confess. Payoffs are (Player 1, Player 2).

Cooperate2, 20, 3

Why (D, D) is the only pure NE (check every cell).
If P2 plays C: P1 gets 2 from C and 3 from D, so D is better. If P2 plays D: P1 gets 0 from C and 1 from D, so D is better. So D is a strictly dominant strategy for P1, and by symmetry for P2. The only profile where both play D is (D, D), with payoff (1, 1). Everyone would prefer (C, C) = (2, 2), but it is not an equilibrium: at (C, C) each player would gain by switching to D (3 > 2).

The question for this whole part: can repetition rescue (C, C)?

2. Finitely repeated Prisoner's Dilemma

2.1 Twice-repeated PD (T = 2): the setup

Two players play the PD in round 1. Both see the outcome. Then they play it again in round 2. Total payoff = round-1 payoff + round-2 payoff. Because round 2 comes after seeing round 1, we must use the extensive form (a game tree).

Round 1 is simultaneous, so Player 2's two nodes are joined by a dashed information set. Round 2 is drawn as a box to save space.

Counting subgames. The whole game is one subgame. Round 2 can start after (C,C), (C,D), (D,C) or (D,D), which gives 4 more. Total 5.
General count for T rounds (this is the "1, 4, 4², 4³, … 4⁹⁹⁹" the lecturer wrote for T = 1000): round t starts after 4t−1 different histories, because each past round has 4 possible outcomes. So number of subgames = 1 + 4 + 4² + … + 4T−1 = (4T − 1) / 3 (The sum comes from the geometric series in Section 4.) Check: T = 2 gives (16 − 1)/3 = 5 ✔. T = 3 gives 21. T = 1000 gives a number with about 600 digits.

2.2 How many strategies? (the 32 × 32 table)

A strategy must say what to do after every history, including histories that will never happen. Here Player 1 decides at: the start of round 1 (1 place) and after each of the 4 round-1 outcomes (4 places). That is 5 decision places, each with 2 actions (C or D).
Number of strategies = 2 × 2 × 2 × 2 × 2 = 2⁵ = 32. So the normal form is a 32 × 32 table (1024 cells). For T rounds the exponent is the number of subgames, so P1 has 2(4T−1)/3 strategies. That is why we never write the table for larger T and use backward induction instead.

How to write a strategy as five letters. Write it as [round 1 ; after CC ; after CD ; after DC ; after DD], where in "after XY" X is Player 1's round-1 action and Y is Player 2's. The lecture's examples:

Check the last one: after CC, P2 cooperated, so C. After CD, P2 defected, so D. After DC, P2 cooperated, so C. After DD, P2 defected, so D. Result D, C, D, C, D ✔.

2.3 Solving T = 2 by backward induction (derivation)

Step 1: round 2 (the last round), inside each of the 4 subgames.
In round 2 there is no future, so nothing can be promised or threatened. Whatever happened in round 1 is already banked. The round-1 payoff is a constant added to every cell, and adding the same number to every cell of a table does not change who wants to switch. So every round-2 subgame is just the ordinary PD again, and D is dominant. All four subgames end in (D, D), adding (1, 1).

Step 2: replace each subgame by its payoff. Round-1 payoff + (1, 1):
Round 1 (P1\P2)CD
C2,2 + 1,1 = 3, 30,3 + 1,1 = 1, 4
D3,0 + 1,1 = 4, 11,1 + 1,1 = 2, 2
Step 3: round 1. In this new table D is still dominant: against C, 4 > 3; against D, 2 > 1 (for P1, and the same for P2 by symmetry). So round 1 is (D, D) too.
Result: the only subgame perfect equilibrium is "defect in both rounds, after every history". Total payoff (2, 2). Cooperation cannot be sustained.

The "unravelling" of cooperation, one round at a time, from the end.

2.4 T = 1000, and the general theorem

Unravelling theorem. If the stage game has a unique Nash equilibrium a*, then for any finite T the repeated game has a unique SPE: play a* in every round, after every history.
Proof by induction (the same three steps, for any T).
Round T: no future, so every player must play a best response to the others inside the stage game. The only profile where everyone does is a*.
Round T−1: the round-T outcome will be a* whatever happens now, so it is a fixed number added to every cell. It does not change anyone's incentive. So round T−1 also has a* as its only equilibrium.
Round T−2, …, round 1: repeat the same argument one step at a time. Each round "inherits" a fixed future and therefore behaves like a one-shot game.
So a* is played in every round. ∎
Example: 1000 rounds of the PD. People often feel that with 1000 chances the players "must" learn to cooperate. The theorem says no: in round 1000 both defect, so in round 999 both defect, … so in round 1 both defect. The lecturer's answer: "players will always defect in this Prisoner's Dilemma kind of setting."
Trap. A long finite game is not the same as an infinite one. The only thing that kills cooperation is that there is a known last round. In an infinite game that last round does not exist, and cooperation can survive (Sections 4 to 5).
Slide summary (two cases).
  • Simultaneous game with a unique NE (or sequential game with a unique SPE) ⟹ the repeated game has a unique SPE (the stage solution every round).
  • Simultaneous game with multiple NE ⟹ the repeated game can have multiple SPE, and some of them are not just "repeat the stage solution". See next section.

3. Finite repetition when the stage game has several equilibria

The unravelling theorem needs a unique stage NE. If there are two stage equilibria, one good for Player 1 and one good for Player 2, the last round can be used as a carrot and a stick: "play nicely in round 1 and I will play the equilibrium you like in round 2; cheat and I will play the one you hate." Because both round-2 outcomes are still stage equilibria, nobody ever wants to break the round-2 plan, so the threat is credible.

3.1 The stage game (from the slides)

P1 \ P2LRC
U4, 30, 01, 4

Finding the pure NE (best-response marking).
P1's best reply to each column: vs L, U (4 > 0). vs R, D (2 > 0). vs C, U (1 > 0).
P2's best reply to each row: vs U, C (4 > 3 > 0). vs D, R (1 > 0).
A cell is an NE when both payoffs are best replies: (U, C) with payoffs (1, 4) and (D, R) with payoffs (2, 1). No other cell works. For instance (U, L): P2's best reply to U is C, not L.

(U, C) is good for P2 (4) and poor for P1 (1). (D, R) is the reverse: good for P1 (2), poor for P2 (1). The best joint outcome is (U, L) = (4, 3) (total 7), but it is not an NE: against U, Player 2 would switch from L to C and get 4 instead of 3. In a one-shot game this outcome is out of reach.

3.2 The tree has 7 subgames

In every round-2 subgame the players must play a stage NE: (U, C) or (D, R). Which one can depend on the history (the lecturer: "a combination of (U,C) or (D,R) could be played"). So the repeated game has many SPE:

3.3 Building the cooperative SPE (the lecture's strategy)

Strategy for Player 1: Round 1: play U. Round 2: play U if Player 2 played L in round 1, otherwise play D.
Strategy for Player 2: Round 1: play L. Round 2: play C if she played L in round 1, otherwise play R.
So the round-2 outcome is: (U, C) if Player 2 played L in round 1 (the carrot, 4 for P2), and (D, R) if she played anything else (the stick, only 1 for P2).

The lecture's version punishes based on what Player 2 did. The summary's version punishes unless the whole outcome was exactly (U, L). Both work; the check below is the same.

Step 1: round-2 subgames. Each one ends in (U, C) or (D, R). Both are stage NE, so nobody can gain by switching alone in round 2. ✔ (This is why the threat is credible.)

Step 2: turn round 1 into a table. Add the round-2 payoff to each round-1 cell. The round-2 payoff is (1, 4) if P2 played L, and (2, 1) if P2 played R or C.
P1 \ P2LRC
U4,3 + 1,4 = 5, 70,0 + 2,1 = 2, 11,4 + 2,1 = 3, 5
D0,0 + 1,4 = 1, 42,1 + 2,1 = 4, 20,0 + 2,1 = 2, 1

This is exactly the table drawn on the lecturer's slide.

Step 3: is (U, L) an NE of this new table?
P1 (column L fixed): U gives 5, D gives 1. 5 > 1. ✔ stays at U.
P2 (row U fixed): L gives 7, R gives 1, C gives 5. 7 is the biggest. ✔ stays at L.
Deviation check in words for P2 (the only tempted one): switching to C earns 4 instead of 3 in round 1 (+1), but moves round 2 from (U, C) paying 4 to (D, R) paying 1 (−3). Net −2, so 7 vs 5. Cooperation wins.
Conclusion: this strategy pair is an SPE. Total payoff (5, 7). That is better for both players than playing (D, R) twice, which gives (4, 2), and better for both than the mixed pairs, which give (3, 5). Only playing (U, C) twice, which gives (2, 8), pays Player 2 more, but then Player 1 gets just 2.
The role of pre-game talk (slide question). Before the game the players can agree on this plan. Normally "cheap talk" is just words. Here the plan is a subgame perfect equilibrium, so no one has a reason to break it. The agreement is self-enforcing, so the pre-game talk is believable.
Conditions for cooperation in a finitely repeated game (remember these): (1) the stage game must have at least two NE with different payoffs, so there is something to threaten with; (2) the last round must always be a stage NE; (3) the cooperative outcome is only used in earlier rounds, and the end-game "reward or punishment" is what holds it up. With a single NE there is no stick, so no cooperation (Section 2).

Infinitely repeated games

4. Infinite games, discounting and present value

4.1 Why study them?

Unravelling started from the last round. If there is no last round, it never starts. Two ways to model this:

  • The game really goes on forever.
  • The game may end after each round with some probability (you never know if today is the last meeting). Mathematically this looks the same as discounting (see 4.3).

4.2 The payoff problem: infinity versus infinity

If we just add payoffs, "2 every round forever" is 2 + 2 + 2 + … = ∞ and "3 now then 1 forever" is also ∞. We cannot compare two infinities. The standard fix: discount the future. A rupee tomorrow is worth less than a rupee today.

Deriving the discount factor from an interest rate r.
Suppose the interest rate per round is r (for example r = 0.10 means 10%). If I put x in the bank today, next round I have x(1 + r). So how much must I put in today to have 2 next round? x(1 + r) = 2  ⟹  x = 2/(1 + r) This x is the present value of receiving 2 next round. Two rounds from now (money grows twice): y(1 + r)² = 2  ⟹  y = 2/(1 + r)² and so on. Therefore the present value of the stream "2 now, 2 next, 2 after that, …" is 2 + 2/(1 + r) + 2/(1 + r)² + … Give 1/(1 + r) a short name: the discount factor δ. A payoff received t rounds from now is multiplied by δt. δ = 1/(1 + r),   r = (1 − δ)/δ

4.3 Adding up the infinite stream: the geometric series (derivation)

We want S = 1 + x + x² + x³ + … for a number 0 < x < 1.
Step 1. Multiply both sides by x: xS = x + x² + x³ + …
Step 2. Subtract: S − xS = 1 (every term except the first cancels).
Step 3. (1 − x)S = 1, so S = 1/(1 − x) Now put x = 1/(1 + r). Then 1 − x = r/(1 + r), so S = (1 + r)/r = 1 + 1/r Two streams the lecture needs:
Always 2: 2 + 2/(1+r) + 2/(1+r)² + … = 2[1 + x + x² + …] = 2(1 + 1/r) = 2 + 2/r.
3 now, then 1 forever: 3 + [1/(1+r)][1 + x + x² + …] = 3 + [1/(1+r)] · [(1+r)/r] = 3 + 1/r.
The same thing in δ. With x = δ: 1 + δ + δ² + … = 1/(1 − δ) and δ + δ² + … = δ/(1 − δ). Therefore always 2:   2/(1 − δ)     |     3 now then 1 forever:   3 + δ/(1 − δ) They agree with the r-version. With δ = 1/(1+r) we have 1 − δ = r/(1+r), so 2/(1−δ) = 2(1+r)/r = 2 + 2/r ✔ and δ/(1−δ) = 1/r so 3 + δ/(1−δ) = 3 + 1/r ✔.
Random ending is the same as discounting. If after each round the game continues with probability δ, then round t is actually played with probability δt, so the expected payoff is Σ δt × (payoff in round t). A patient player (high δ) is one who expects the game to continue.
Traps. (1) High δ (close to 1) = patient = low interest rate. Cooperation needs patience. (2) "r < 1" and "δ > ½" are the same condition written two ways. (3) The geometric formula needs x < 1; at δ = 1 sums are infinite again.

5. Trigger strategies: Grim and Tit-for-Tat

In the infinite game, "always defect" is still an equilibrium (a stage NE repeated). The interesting question is whether other equilibria exist. They do, because a strategy can depend on history: "If you misbehave this round, I will respond next round." That threat only exists if there is a next round, which is the point of the infinite horizon.

Trigger strategy: (1) begin by cooperating; (2) keep cooperating as long as the rival does; (3) on seeing a defection, immediately switch to a period of punishment (where everyone plays non-cooperatively). If the threat is strong enough to change behaviour, we have found a trigger strategy equilibrium.

5.1 The two extremes

Two goals pull in opposite directions: deterrence (the punishment is big enough that cheating does not pay) and credibility (the punishment is something the punisher will really carry out). GTS is big but hurts the punisher too; TFT is mild and cheap.

5.2 When does cooperation beat defection against Grim Trigger? (the main derivation)

Take the PD with (C,C) = (2,2), (C,D) = (0,3), (D,C) = (3,0), (D,D) = (1,1). Both players use grim trigger. Look at Player 1 at round 0 (the argument is the same every round, see below).

Defecting wins big at t = 0 (3 vs 2) but loses 1 every round afterwards (1 vs 2).

Option A: cooperate forever. Both play C every round, so payoffs 2, 2, 2, … with present value Vcoop = 2 + 2δ + 2δ² + … = 2/(1 − δ)   (in r: 2 + 2/r) Option B: defect now. Player 1 plays D while Player 2 plays C: she gets 3. From then on Player 2 plays D forever, and Player 1's best reply to D is D, which gives 1 each round: Vdev = 3 + δ + δ² + … = 3 + δ/(1 − δ)   (in r: 3 + 1/r) Cooperate if Vcoop ≥ Vdev: 2/(1 − δ) ≥ 3 + δ/(1 − δ) Multiply both sides by (1 − δ), which is positive: 2 ≥ 3(1 − δ) + δ = 3 − 2δ  ⟹  2δ ≥ 1  ⟹  δ ≥ ½ The lecture's version with r: 2 + 2/r > 3 + 1/r ⟹ 1/r > 1 ⟹ r < 1. Same thing: δ = 1/(1+r) > ½ ⟺ r < 1.
Meaning: the one-time gain is 3 − 2 = 1; the loss is 2 − 1 = 1 every round after. The loss lasts forever, so unless the player is extremely impatient (interest rate above 100%), she cooperates. For δ < ½ she defects.
Why checking only "defect at round 0, then D forever" is enough.
(1) Timing doesn't matter. If she defects at round t instead, every payoff is multiplied by δt on both sides, so the inequality is unchanged.
(2) After the first defection, D forever is her best reply, because the other player now plays D forever and D is the best reply to D. So a longer plan such as "defect, then cooperate again" can only do worse. Hence the one test above covers all deviations.
(3) Is the punishment itself believable? After a defection both play (D, D) forever. (D, D) is a Nash equilibrium of the stage game, so neither player wants to deviate from it in any later round. So grim trigger is an equilibrium in every subgame: it is a subgame perfect equilibrium for δ ≥ ½.
Numbers. δ = 0.6: Vcoop = 2/0.4 = 5. Vdev = 3 + 0.6/0.4 = 4.5. Cooperate (5 > 4.5). δ = 1/3: Vcoop = 3, Vdev = 3 + 0.5 = 3.5. Defect (3.5 > 3). δ = ½: both are 4, indifferent. Confirms the threshold.
About "lacks credibility" on the slide. (My reading of the slide.) Forever-punishment can be costly to the punisher. In this PD it is free to the punisher, because D is the best reply to D anyway, so the threat is credible. In other games, if the punishment action is not a best reply to what the rival then plays, the punisher would rather drop the threat, and then grim trigger would fail subgame perfection.

5.3 Tit-for-Tat: the slide's calculation, and a careful check

The slide's stream. Cooperate: 2, 2, 2, …. Defect: "3 today, 1 tomorrow, 2 from the day after tomorrow." Comparing present values (the terms from the third onwards are equal and cancel):

2 + 2/(1 + r) > 3 + 1/(1 + r)  ⟹  1/(1 + r) > 1  ⟹  1 > 1 + r  ⟹  r < 0 Since an interest rate cannot be negative, the slide concludes that this deviation always pays, so cooperation is not supported by this calculation.
Careful: this stream cannot actually happen against Tit-for-Tat. (This is my own check, not on the slide.) TFT copies your last move. If you defect at t = 0 (you get 3) and defect again at t = 1 (you get 1), TFT plays D at t = 2, so at t = 2 you cannot get 2: you get 1 (if you play D) or 0 (if you play C). The stream 3, 1, 2, 2, … would need TFT to "forgive" for free.

Correct check: defect once, then go back to cooperating. Against TFT you get 3 at t = 0 (you play D, they play C). At t = 1 you play C but TFT punishes: you get 0. From t = 2, TFT copies your C, so you get 2 again. 3 + 0·δ + 2δ² + 2δ³ + … = 3 + 2δ²/(1 − δ) Compare with cooperating, 2/(1 − δ). Cooperating is at least as good when 2 ≥ 3(1 − δ) + 2δ²  ⟺  0 ≥ 1 − 3δ + 2δ² = (1 − δ)(1 − 2δ)  ⟺  δ ≥ ½ Defecting forever against TFT gives 3 + δ/(1 − δ), the same as against grim trigger, which again needs δ ≥ ½. I also tested every other deviation pattern by computer: for δ ≥ ½ none beats cooperating. So TFT is a Nash equilibrium for δ ≥ ½.
For the exam: know the slide's comparison method (write the two streams, compare, solve). If a question hands you a specific stream, just compare it the same way. For grim trigger the clean threshold is δ ≥ ½ (r ≤ 1).

5.4 Tit-for-Tat is not subgame perfect (slide 26)

Setup. At t = 0 Player 1 cooperates and Player 2 defects: outcome (C, D). Now both follow TFT.
t = 1: P1 copies P2's D, so plays D. P2 copies P1's C, so plays C. Outcome (D, C): P1 gets 3, P2 gets 0.
t = 2: P1 copies P2's C → C. P2 copies P1's D → D. Outcome (C, D): P1 gets 0, P2 gets 3.
They alternate forever: P1 gets 3, 0, 3, 0, … from t = 1. P1's value from t = 1 under TFT: 3 + 3δ² + 3δ⁴ + … = 3/(1 − δ²) = 3/[(1 − δ)(1 + δ)] A better plan for P1 in this subgame: play C at t = 1 even though TFT says D. P2 plays C, so (C, C) = 2. P2 then copies P1's C, and cooperation resumes forever: value 2/(1 − δ). Compare: 2/(1 − δ) > 3/[(1 − δ)(1 + δ)]  ⟺  2(1 + δ) > 3  ⟺  δ > ½ So for δ > ½ Player 1 gains by not following TFT in this subgame. TFT is not a best reply in every subgame, so it is not subgame perfect. Grim trigger has no such problem: after a defection both just play D, which is a stage NE.

6. The folk theorem: which outcomes can be equilibria?

Grim trigger shows that (C, C) can be an equilibrium. Can we describe all equilibrium outcomes of an infinitely repeated game? The folk theorem does that. Questions the lecture raises: is it subgame perfect or not? Averaged or discounted utilities? The easiest case first: averaged utilities, no subgame perfection.

Average utility: if a player's payoffs over time are u0, u1, …, her average utility is the long-run average of these. Patience is perfect, so only the long-run mix of outcomes matters.
Feasible: a payoff vector (u1, …, un) is feasible if some mix of stage outcomes gives each player that average. Geometrically: any point in the convex hull (the filled polygon) of the stage-game payoff vectors.
Enforceable: a payoff for a player is enforceable if the others can prevent her from getting more than she asked by deviating, i.e. she gets at least what she can guarantee herself, her minmax (reservation) payoff. Otherwise she would deviate and secure her guarantee.
Folk theorem (slide version). A payoff vector can be realised by some Nash equilibrium of the infinitely repeated game (with average utilities) if and only if it is feasible and enforceable.

Applying it to the PD

Minmax in the PD. The worst the other can do to you is play D. Your best reply to D is D, so you still get 1. So each player's guarantee is 1, and enforceable means ui ≥ 1.
Slide examples. u₁ = 0.5 is not enforceable: Player 1 can guarantee herself 1 by playing D, so she would never accept 0.5. u₁ = 1.2 is enforceable: Player 2 can hold her down to at most 1 by playing D, so a promise of 1.2 is one she cannot get more than by cheating, and the threat of punishment (back to 1) deters cheating.
Feasible region. The convex hull of (2,2), (0,3), (3,0), (1,1): the quadrilateral in the picture. Folk region = feasible and u₁ ≥ 1 and u₂ ≥ 1.

Blue = feasible payoffs. Green = feasible and enforceable (u₁ ≥ 1 and u₂ ≥ 1). Its corners are (1,1), (1,2.5), (2,2) and (2.5,1).

Where do the corners come from? The top edge of the blue shape joins (0,3) and (2,2): the line u₂ = 3 − u₁/2, which at u₁ = 1 gives u₂ = 2.5. The right edge joins (2,2) and (3,0): u₂ = 6 − 2u₁, which at u₂ = 1 gives u₁ = 2.5.
Example of realising a point. (1.5, 2.25) is on the top edge: it is the average of (2,2) (weight ¾) and (0,3) (weight ¼): 0.75·2 + 0.25·0 = 1.5 and 0.75·2 + 0.25·3 = 2.25. Play (C,C) three rounds, then (C,D) one round, repeating. If anyone deviates, everyone plays D forever, dropping the deviator to 1, which is less than what she gets (≥ 1.5 for P1, 2.25 for P2). So no one deviates.
Why "if and only if"? (sketch.) Only if: a payoff has to be an average of stage outcomes (feasible), and a player getting less than her guarantee would deviate (so it must be enforceable). If: let the players cycle through outcomes that average to the target vector. If anyone deviates, the others punish her forever by holding her to her minmax; since the target is at least her minmax, the deviation does not pay.
Stronger version (lecture summary). With discounting and requiring subgame perfection: any feasible payoff vector in which every player gets strictly more than her reservation payoff (for example the stage-NE payoff) can be sustained as an SPE if δ is close enough to 1. In the PD this means almost anything in the green region, including cooperation (2,2).
Message. The folk theorem shows that repeated games have very many equilibria. It does not predict which one will be played. It only says cooperation can be sustained, not that it will be.

The surprising point: game-theory ideas still apply even when no one is reasoning, because what matters is how well a behaviour does against the other behaviours around it.

7.1 The biology in four lines

  1. Genes are the main determinants of observable characteristics. In a given environment, these characteristics decide an organism's fitness.
  2. More fit organisms (on average) produce more offspring.
  3. So the genes giving greater fitness have a larger share of the next generation.
  4. This is natural selection as the mode of evolution.

7.2 Why it becomes a game

An organism's success depends on how it interacts with others. You cannot measure the fitness of one organism alone; you must look at the whole population it lives in. That is exactly a game.

7.3 The beetle example (Easley and Kleinberg, as in the lecture)

Puzzle. A beetle's fitness depends on finding and processing food. Suppose a mutation makes some beetles larger. Large beetles need more food to keep going, which seems to make them less fit. So you would expect the mutation to die out. Is that what happens? Let us see.

Assumptions (slides). Beetles compete in random pairs for food (never the same pair twice). (1) Two beetles of the same size share equally. (2) If sizes differ, the large one gets the majority share. (3) For the same quantity of food, a large beetle is less fit than a small one (higher upkeep). Beetles do not decide their size: it is hard-wired in their genes, and natural selection acts over a longer time scale (generations).
Beetle 1 \ Beetle 2SmallLarge
Small6, 61, 10
Large10, 14, 4
Reading the numbers. (Small, Small): share equally, fitness 6 each. (Large, Large): share equally, but both pay high upkeep, so only 4 each. (Large vs Small): the large one takes most of the food: 10 for Large, 1 for Small.
Notice: this is the Prisoner's Dilemma. Small = Cooperate, Large = Defect. Large is a dominant strategy (10 > 6 and 4 > 1), yet (Small, Small) = (6, 6) beats (Large, Large) = (4, 4).

8. Evolutionarily Stable Strategies (ESS)

A Nash equilibrium assumes players choose best replies. Beetles do not choose. What we want instead is a trait that, once it is common, cannot be taken over by a rare mutant.

Incumbents and mutants. Suppose almost everyone plays strategy S (the incumbents). A small fraction x of the population switches (mutates) to strategy T. So a fraction 1 − x plays S and a fraction x plays T. A beetle's fitness = its average payoff against a randomly met opponent.
Definition (slide). Strategy S is an evolutionarily stable strategy if for every other strategy T there is some number y > 0 such that, whenever the mutant share is x < y, fitness of an S-player  >  fitness of a T-player "Evolutionarily stable" = mutants have strictly lower reproductive success, so they die out.
Where the expected-fitness formula comes from. An S-player meets another S-player with probability 1 − x and a T-player with probability x. Averaging her two payoffs with these probabilities: fitness(S) = (1 − x)·u(S,S) + x·u(S,T). Likewise fitness(T) = (1 − x)·u(T,S) + x·u(T,T).

8.1 Beetles: is Small an ESS?

Incumbents Small (1 − x), mutants Large (x).
Small beetle: meets Small with probability 1 − x (payoff 6), meets Large with probability x (payoff 1): 6(1 − x) + 1·x = 6 − 5x.
Large beetle: meets Small with probability 1 − x (payoff 10), meets Large with probability x (payoff 4): 10(1 − x) + 4x = 10 − 6x.
Compare: (10 − 6x) − (6 − 5x) = 4 − x. This is positive for every x between 0 and 1. So the Large mutant does better than the Small incumbent, however few mutants there are.
Conclusion: a few large beetles do really well because they rarely meet each other and win most of the food. Small beetles cannot drive them out. Small is NOT an ESS.

8.2 Beetles: is Large an ESS?

Incumbents Large (1 − x), mutants Small (x).
Large beetle: meets Large with probability 1 − x (payoff 4), meets Small with probability x (payoff 10): 4(1 − x) + 10x = 4 + 6x.
Small beetle: meets Large with probability 1 − x (payoff 1), meets Small with probability x (payoff 6): 1(1 − x) + 6x = 1 + 5x.
Compare: (4 + 6x) − (1 + 5x) = 3 + x > 0 for every x. So the incumbent Large beats the Small mutant for all x (so any y works).
Conclusion: small mutants lose almost every competition for food. A population of large beetles resists invasion. Large IS an ESS.

The Large line is above the Small line everywhere (gap 4 − p), so the share of Large only grows, up to p = 1. This is the lecturer's drawing "small can be successfully attacked by large". (Section 8.2's x is 1 − p.)

The sad result (slides). Evolution makes everyone's fitness fall: from 6 each (all Small) to 4 each (all Large). Darwin's idea is that natural selection raises fitness in a fixed environment. But for a beetle the environment includes all the other beetles. As Large spreads the environment becomes more hostile for everyone. Selection is blind to the population's total; it only rewards doing better than the others you meet. That is the Prisoner's Dilemma again, with genes doing the choosing.

8.3 ESS and Nash equilibrium

Take any symmetric 2×2 game (payoffs depend only on the strategies used, not on who plays them; swap the players and nothing changes):

ST
Sa, ab, c
Tc, bd, d

The payoff to the row player is a (S vs S), b (S vs T), c (T vs S), d (T vs T).

When is (S, S) a Nash equilibrium? S must be a best reply to S: a ≥ c.
When is S an ESS? We need fitness(S) > fitness(T) for small x: (1 − x)a + xb  >  (1 − x)c + xd Collect terms: (a − c)(1 − x) + (b − d)x > 0, or equivalently f(x) = (a − c) + x[(b − d) − (a − c)]  >  0 Look at x very close to 0:
• If a > c: f(0) = a − c > 0, and f changes smoothly, so f(x) > 0 for all small enough x. ✔ ESS.
• If a < c: f(0) < 0, so f(x) < 0 for small x. ✘ not ESS.
• If a = c: then f(x) = x(b − d), which is positive (for x > 0) exactly when b > d. So ESS if b > d, not ESS if b ≤ d.
So: S is an ESS ⟺ a > c, or (a = c and b > d). The first-order test is the same as the Nash test, but strict.
Relationship (slide and summary):
  1. If S is an ESS, then (S, S) is a symmetric Nash equilibrium (because a > c, or a = c, both give a ≥ c).
  2. If (S, S) is a strict Nash equilibrium (a > c), then S is an ESS.
  3. The converse is false: not every symmetric NE is an ESS.
The slide's question: what if a = c and b < d? Then (S, S) is a (weak) NE because a ≥ c, but S is not an ESS. Example: a = 1, b = 0, c = 1, d = 2. Mutant T against S earns c = 1, the same as S against S, so T is not at a disadvantage at first. But when mutants meet each other they earn d = 2, more than S earns against a mutant (b = 0). Check: fitness(S) = (1 − x)·1 + x·0 = 1 − x; fitness(T) = (1 − x)·1 + x·2 = 1 + x. T wins for every x > 0. So the mutant takes over.
Trap. "ESS" is stronger than "symmetric NE". NE only asks for "no strictly better alternative". ESS asks that every mutant does strictly worse when it is rare, and if it ties against the incumbents, it must still do worse against itself.

8.4 Application: why is the sex ratio 1 : 1? (Fisher)

A small calculation behind the story (my explanation; the slide gives words only). Each child has exactly one mother and one father. So if a generation has N children, the total number of "child slots" belonging to all mothers is N, and the same N for all fathers. With F females and M males, an average female has N/F children and an average male has N/M. If females are scarce (F < M), then N/F > N/M: a daughter is worth more grandchildren than a son. Genes for producing daughters win until F = M. Then N/F = N/M and the advantage vanishes.

9. The Hawk-Dove game: why aggression exists, but is not always seen

Setup. Two indistinguishable individuals contest a resource of value V > 0. Each chooses Hawk (H): demand it and fight, or Dove (D): share peacefully (retreat if the other is a Hawk).
• Hawk vs Dove: the Hawk gets all of V; the Dove gets 0.
• Dove vs Dove: they share, V/2 each.
• Hawk vs Hawk: they fight. Each wins with probability ½ (and gets V). The loser pays an injury cost C. We assume C > V (fighting is costly).
Payoff of Hawk against Hawk. With probability ½ I win and get V. With probability ½ I lose and pay C (a payoff of −C). Average: ½V + ½(−C) = (V − C)/2. Since C > V this is negative.
Row \ ColumnHawkDove
Hawk(V−C)/2, (V−C)/2V, 0
Dove0, VV/2, V/2

9.1 Neither pure strategy is an ESS

All Hawks? A Dove mutant against a Hawk gets 0. A Hawk against a Hawk gets (V − C)/2 < 0. Since 0 > (V−C)/2, Doves do better. Doves invade. Hawk is not an ESS. (In the language of 8.3: a = (V − C)/2 < c = 0.)
All Doves? A Hawk mutant against a Dove gets V. A Dove against a Dove gets V/2. V > V/2, so Hawks do better. Hawks invade. Dove is not an ESS. (Here a = V/2 < c = V.)
So the population settles at a mix.

9.2 The mix: derive the equilibrium fraction

Let a fraction p of the population be Hawks and 1 − p Doves. Random pairing.
Hawk's fitness. Meets a Hawk with probability p (payoff (V−C)/2), meets a Dove with probability 1 − p (payoff V): H(p) = p(V − C)/2 + (1 − p)V = V − pV/2 − pC/2 = (1 − p/2)V − (p/2)C Dove's fitness. Meets a Hawk (probability p) and gets 0; meets a Dove (probability 1 − p) and gets V/2: D(p) = p·0 + (1 − p)V/2 = (1 − p)V/2 Equilibrium: both types do equally well (if one did better, its share would grow). Set H(p) = D(p): V − pV/2 − pC/2 = V/2 − pV/2 The terms −pV/2 cancel on both sides: V − pC/2 = V/2  ⟹  V/2 = pC/2  ⟹  p* = V/C Since C > V, p* is between 0 and 1. Higher injury costs ⟹ fewer Hawks. The common fitness at p* is (V/2)(1 − V/C), smaller than V/2, which is what an all-Dove population would earn. Like the beetles, the equilibrium population does worse than a peaceful one.
Slide example: V = 6, C = 10.
Hawk: (1 − p/2)·6 − (p/2)·10 = 6 − 3p − 5p = 6 − 8p.
Dove: (1 − p)·6/2 = 3 − 3p.
Equal: 6 − 8p = 3 − 3p ⟹ 3 = 5p ⟹ p* = 3/5. (Check: V/C = 6/10 ✔.) Common fitness = 3 − 3(0.6) = 1.2.
In words: 60% Hawks and 40% Doves.

Left of p* the Hawk line is higher, so Hawks multiply and p moves right. Right of p* the Dove line is higher, so Hawks shrink and p moves left. The arrows point to p*, so p* is stable.

The lecturer's second example (numeric table). Matrix: (H,H) = (−2, −2), (H,D) = (10, 0), (D,H) = (0, 10), (D,D) = (5, 5). That is V = 10 and C = 14, because (V − C)/2 = −2 ✔ and V/2 = 5 ✔. Here the lecturer lets p be the fraction of Doves (the label 1 − p sits over Hawk).
Hawk's fitness: −2(1 − p) + 10p = 12p − 2. Dove's fitness: 0(1 − p) + 5p = 5p.
Equal: 12p − 2 = 5p ⟹ 7p = 2 ⟹ p = 2/7 Doves, so 5/7 Hawks. Check with the formula: V/C = 10/14 = 5/7 ✔.
Watch the labelling: in the first example p = fraction of Hawks, in this one p = fraction of Doves. Always state what your p means.

9.3 Proof that p* = V/C is really an ESS

(Extra: not on the slides, but it shows why the mixed point is stable and not just "equal fitness".)
Let a mutant play Hawk with probability q (or be a fraction q of Hawk-types). Write E(p, q) for the fitness of playing Hawk with probability p against a population playing Hawk with probability q: E(p, q) = p·H(q) + (1 − p)·D(q).
Step 1: at p*, Hawk and Dove tie. H(p*) = D(p*). So against p*, every strategy q earns the same as p*: E(q, p*) = E(p*, p*). That is the "a = c" case from 8.3, so we need the second test: p* must do better against the mutant than the mutant does against itself.
Step 2: compute the gap H(q) − D(q). H(q) − D(q) = [V − qV/2 − qC/2] − [V/2 − qV/2] = V/2 − qC/2 = (C/2)(V/C − q) = (C/2)(p* − q) Step 3: the second test. E(p*, q) − E(q, q) = p*H(q) + (1 − p*)D(q) − qH(q) − (1 − q)D(q) = (p* − q)[H(q) − D(q)] = (C/2)(p* − q)² This is positive for every q ≠ p*. So p* beats every mutant: it is an ESS. (I also checked this identity numerically.)
Two ways to read the mixed ESS. (1) Population polymorphism: a fraction p* of the animals are born Hawks and 1 − p* are born Doves, and the proportions stay stable. (2) Mixed strategy: every individual plays Hawk with probability p*. Both give the same stability. Message of the model: aggression is present in a population but is not always seen, and its level falls as injuries become more costly (p* = V/C).

Check the general PD formula. Cooperate: R/(1 − δ). Deviate: T now, then P forever: T + δP/(1 − δ). R ≥ T(1 − δ) + δP ⟹ R ≥ T − δ(T − P) ⟹ δ(T − P) ≥ T − R ⟹ δ ≥ (T − R)/(T − P). With R = 2, T = 3, P = 1: (3 − 2)/(3 − 1) = ½ ✔.

Common mistakes

  • Writing a strategy as one action. In a repeated game it is a plan for every history (32 strategies for T = 2, not 2).
  • Expecting cooperation in a long but finite PD. Unique stage NE + finite T ⟹ defect every round.
  • Mixing up δ and r. Patient = large δ = small r. δ ≥ ½ ⟺ r ≤ 1.
  • Forgetting to check the punishment. The punishment phase must be a best reply (a stage NE) to be believable.
  • Calling every symmetric NE an ESS. ESS is stricter.
  • Forgetting what p means in Hawk-Dove (fraction of Hawks or of Doves).
  • Using the folk theorem as a prediction. It says what is possible, not what will happen.

11. Practice questions (try first, then open the answer)

Q1. Grim trigger with other payoffs

PD stage game: (C,C) = (4,4), (C,D) = (0,6), (D,C) = (6,0), (D,D) = (1,1), repeated infinitely, both players use grim trigger. Find the smallest δ and the largest interest rate r for which cooperation is an equilibrium.

Solution. Vcoop = 4/(1 − δ). Vdev = 6 + δ·1/(1 − δ). Need 4/(1−δ) ≥ 6 + δ/(1−δ). Multiply by (1 − δ): 4 ≥ 6(1 − δ) + δ = 6 − 5δ ⟹ 5δ ≥ 2 ⟹ δ ≥ 2/5. Since δ = 1/(1 + r): 1 + r ≤ 5/2 ⟹ r ≤ 3/2 = 150%. (Check with the formula (T − R)/(T − P) = (6 − 4)/(6 − 1) = 2/5 ✔.)
Q2. Counting

The PD is played 3 times. How many subgames are there? How many strategies does Player 1 have?

Solution. Subgames: 1 + 4 + 16 = 21 = (4³ − 1)/3 ✔. Player 1 has 21 decision places (1 in round 1, 4 in round 2, 16 in round 3), each with 2 actions, so 2²¹ = 2,097,152 strategies.
Q3. Finite repetition

A stage game with exactly one Nash equilibrium is repeated 50 times. Can an outcome that is not that equilibrium be played in round 1 of a subgame perfect equilibrium? What if the stage game had two equilibria?

Solution. With a unique stage NE, no: the unravelling theorem says every round plays that NE. With two (or more) stage equilibria with different payoffs, yes, in earlier rounds: use one as a reward and the other as a punishment in the final rounds, as in Section 3 (outcome (U, L) in round 1).
Q4. ESS tests

For each symmetric game find which strategies are ESS. (a) u(S,S) = 2, u(S,T) = 0, u(T,S) = 1, u(T,T) = 3. (b) u(S,S) = 1, u(S,T) = 0, u(T,S) = 1, u(T,T) = 2.

(a) For S: a = 2 > c = u(T,S) = 1 ⟹ ESS. For T: its own "a" = u(T,T) = 3 > u(S,T) = 0 ⟹ ESS. Both are ESS (a coordination game: whichever is common stays common).
(b) For S: a = 1 = c = 1, so compare b = u(S,T) = 0 with d = u(T,T) = 2. b < d ⟹ S is a NE but not an ESS (T invades: fitness(S) = 1 − x, fitness(T) = 1 + x). For T: u(T,T) = 2 > u(S,T) = 0 ⟹ T is an ESS.
Q5. Hawk-Dove

V = 8, C = 12. Find the stable fraction of Hawks and the fitness at that point. What happens to the fraction if C doubles?

Solution. p* = V/C = 8/12 = 2/3. Hawk: (1 − p/2)V − (p/2)C = (2/3)(8) − (1/3)(12) = 16/3 − 4 = 4/3. Dove: (1 − p)V/2 = (1/3)(4) = 4/3 ✔ equal. If C = 24: p* = 8/24 = 1/3, so fewer Hawks. (An all-Dove population would earn V/2 = 4, more than 4/3: the mix is worse for everyone.)
Q6. Folk theorem

In the PD with (C,C) = (2,2), (C,D) = (0,3), (D,C) = (3,0), (D,D) = (1,1) (average utilities), say whether each vector is feasible and enforceable: (a) (0.8, 2), (b) (2.5, 2.5), (c) (1.5, 2).

Solution. Enforceable means each coordinate ≥ 1. Feasible means inside the quadrilateral with corners (0,3), (2,2), (3,0), (1,1).
(a) 0.8 < 1, not enforceable (Player 1 can secure 1 by defecting). (b) At u₁ = 2.5 the upper boundary of the shape is the edge from (2,2) to (3,0), u₂ = 6 − 2u₁ = 1. So u₂ can be at most 1 there, and 2.5 is far above: not feasible. (c) At u₁ = 1.5 the feasible u₂ runs from 0.75 to 2.25, so 2 is inside: feasible, and 1.5 ≥ 1, 2 ≥ 1: enforceable. So (c) can be a Nash equilibrium outcome.
