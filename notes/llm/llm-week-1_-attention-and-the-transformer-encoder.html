1. Background: text as numbers

1.1 Why sequences are special

Language is a sequence: order matters ("dog bites man" is not "man bites dog") and length varies from sentence to sentence. A model for language must (a) accept variable length input and (b) use the meaning of each word in context.

1.2 Word embeddings

Computers cannot use words directly, so each word is mapped to a vector of numbers called a word embedding. In the slides, toy 3-dimensional embeddings are used: "I" = [1,0,0], "enjoyed" = [0,1,0], "the" = [1,1,0], "movie" = [1,0,1], "transformers" = [1,1,1]. In the real model these have 512 numbers.

Static vs contextual embeddingsStatic (Word2Vec, GloVe): each word has one fixed vector regardless of the sentence. The word "bank" gets the same vector in "river bank" and "bank loan". Contextual: the vector for a word changes depending on the other words around it. RNN hidden states and Transformer outputs are contextual.

Notation used throughout: a sentence has $T$ words (the slides also use $n$); $h_1,\dots,h_T$ are the input vectors; $z_1,\dots,z_T$ are the context-aware outputs.

3. RNNs in detail and their limits

3.1 How an RNN works

An RNN keeps a memory called the hidden state. At every step it reads one word $X_t$ and updates the memory using the old memory:

$$H_t=f(H_{t-1},X_t),\qquad\text{commonly}\quad H_t=\tanh(W_hH_{t-1}+W_xX_t+b)$$

Because $H_t$ depends on $H_{t-1}$, which depends on $H_{t-2}$ and so on, $H_t$ summarises $X_1,\dots,X_t$. So each $H_t$ is a contextual representation of word $t$ using only the left context.

3.2 Bidirectional RNN

To also use the right context, run a second RNN from right to left and join the two states: $[H_t^{fwd}\,;\,H_t^{bwd}]$. This gives each word information from both sides, but you still need two sequential passes.

3.3 Problem 1: no parallelism

The sequential bottleneckThe whole sentence $X_1..X_T$ is available at time 0, yet $H_t$ cannot be computed until $H_{t-1}$ is finished. A GPU has thousands of cores but an RNN can use only one "column" of work at a time along the sentence. Training time grows linearly with length and cannot be sped up by adding hardware along that direction.

3.4 Problem 2: vanishing / exploding gradients

Training uses backpropagation through time. The gradient of a late loss with respect to an early hidden state is a product of many Jacobians:

$$\frac{\partial H_t}{\partial H_k}=\prod_{j=k+1}^{t}\frac{\partial H_j}{\partial H_{j-1}}$$

If these factors are usually smaller than 1 the product shrinks to almost 0 (vanishing, the model forgets far-away words). If usually bigger than 1 it blows up (exploding, unstable training). Long-distance links are therefore hard to learn. (LSTMs/GRUs reduce, but do not remove, this.) The lecture lists "get rid of vanishing/exploding gradients" in its wishlist.

4. Sequence-to-sequence (encoder-decoder)

Many tasks map one sequence to another: translation, summarisation, question answering. The seq2seq model uses two RNNs.

  • Encoder RNN reads the source sentence and produces hidden states $h_1..h_5$.
  • The final state $h_5$ is the concept vector (also called thought vector, context vector or annotation).
  • Decoder RNN is started with $s_0=h_5$ and generates the target words one by one.

4.1 How the decoder produces words

At each step the decoder state $s_t$ is passed through a softmax over the vocabulary; the most likely word is the output $y_t$. It starts from a special <Go> token. During training the true previous word is fed as input (Naan, then transfarmar, then padaththai), even if the model guessed wrongly; this is called teacher forcing.

4.2 Limitations

Two problems1. Information bottleneck: the entire sentence must fit in one vector $h_5$, so long sentences lose detail. 2. No alignment: the decoder does not know which source word to look at while producing each target word. The lecture says: "Attention mechanism resolves this."

5. Attention in seq2seq

5.1 The idea

Human translators glance back at the specific source word they are translating. Attention lets the decoder do the same. Make a copy of all encoder states $h_1,\dots,h_n$ and hand them to the decoder (the encoder itself can then be dropped until decoding ends). At each decoder step, the decoder decides how much to look at each $h_i$.

5.2 Context vector

$$c_t=\sum_{i=1}^{n}\alpha_{ti}\,h_i\quad\text{(context for output }y_t\text{)}$$

$n$ = number of source words, $t$ = decoder time step, $\alpha_{ti}$ = attention weight of source word $i$ at step $t$. As a matrix product: $c_t=[\,h_1\ h_2\ \dots\ h_n\,]\,[\alpha_{t1},\dots,\alpha_{tn}]^T$. The context $c_t$ (together with the previous output word) is fed into decoder state $s_t$. So the decoder gets a new context at every step instead of one fixed vector.

5.3 Getting the weights

$$e_{ti}=\text{score}(s_{t-1},h_i),\qquad \alpha_{ti}=\text{align}(y_t,h_i)=\frac{\exp(e_{ti})}{\sum_{i'=1}^{n}\exp(e_{ti'})}$$
  1. Compare the decoder's current state $s_{t-1}$ with each source state $h_i$ using a score function. High score means "relevant".
  2. Apply softmax so the weights are positive and add up to 1 (a probability distribution over source words). The exponential also makes the largest scores stand out.

The score used in the seq2seq attention slide is the additive (Bahdanau-style) form:

$$\text{score}(s_{t-1},h_j)=V_a^{T}\tanh\!\big(U_{att}\,s_{t-1}+W_{att}\,h_j\big)$$

It has two linear maps ($U_{att}$ on the decoder state, $W_{att}$ on the encoder state), one non-linearity (tanh) and a final dot product with the learned vector $V_a$. Note it involves three vectors: $s$, $h$ and $V_a$. Keep this in mind: it is exactly what Q, K, V will replace.

6. What can and cannot be parallelized

Q1. Can $\alpha_{ti}$ be computed in parallel for all $i$ at one step $t$?Yes. All $h_i$ are already available and $s_{t-1}$ is fixed, so each $e_{ti}$ is independent. Take-away: attention itself can be parallelized.
Q2. Can the encoder states $h_i$ be computed in parallel for all $i$?No, each needs the previous one.
Q3. Can $\alpha_{ti}$ be computed for all decoder steps $t$ at once?No. $\alpha_{t}$ needs $s_{t-1}$, which needs $c_{t-1}$, which needs $\alpha_{t-1}$. This is a chain.

8. Self-attention: the motivation

8.1 The pronoun puzzle

"The animal didn't cross the street because it was too tired." → "it" = animal
"The animal didn't cross the street because it was too congested." → "it" = street

Only one word changed (tired → congested) but the meaning of "it" flipped. A fixed embedding cannot do this. The model must connect "it" to the right word based on context. That is what attention does. Since the connection is between words of the same sentence, it is called self-attention (as opposed to cross-attention between two different sequences, e.g. decoder ↔ encoder, seen in section 5).

8.2 The goal: a relation table

For every word we want a score against every other word in the sentence, higher when they are contextually related. The slide's example (rows = current word, columns = other words):

8.3 Why it can be parallel

Key difference from seq2seq attentionIn seq2seq, all $h_j$ were known but the decoder states $s_i$ appeared one at a time. In self-attention both sides come from the same input, so every vector is available at time 0. All rows of the table can therefore be computed at the same time.

9. Deriving Query, Key and Value

9.1 The problem

The additive score used three vectors ($s$ = who is asking, $h$ = who is being compared, and $V_a$). In self-attention the layer only receives the word embeddings $h_j$. So we must obtain the needed vectors from each embedding.

9.2 The solution: linear projections

Multiply each embedding by three learnable matrices. Three matrices are needed because there are three roles:

$$q_j=W_Q\,h_j,\qquad k_j=W_K\,h_j,\qquad v_j=W_V\,h_j$$

The entries of $W_Q,W_K,W_V$ are ordinary parameters, initialised randomly and learned by backpropagation. Sizes in the lecture: $h_j\in\mathbb R^{512}$ and $q_j,k_j,v_j\in\mathbb R^{64}$, so each $W$ is $64\times512$. (The slide draws small toy matrices; the point is that they are matrices.)

Why separate roles helpIf the same vector were used for matching and for content, a word would be forced to be equally good at "being found" and "giving information". With separate $W_Q,W_K,W_V$ the model can learn, for example, that a pronoun should ask for nouns, nouns should advertise themselves as nouns, and what they pass on is their meaning.

9.3 Dot product as the score function

The lecture replaces the tanh score by a plain dot product between a query and a key: $\text{score}(q_i,k_j)=q_i\cdot k_j$. It is large when the two vectors point in a similar direction. It is also just a matrix multiplication, which is very fast on GPUs. In the old formula "Fixed" was $s_{t-1}$ and "variable" was $h_j$; now Fixed is $q_i$ and variable is $k_j$.

10. Computing self-attention: step by step with numbers

10.1 The four steps for one word

Take word $i$ (say the first word, "I"). For an input $h_1..h_T$:

  1. Project all words: $q_i=W_Qh_i$, $k_j=W_Kh_j$, $v_j=W_Vh_j$.
  2. Score word $i$ against every word $j$: $e_{ij}=q_i\cdot k_j$ (so $e_{1j}=[q_1\!\cdot\!k_1,\ q_1\!\cdot\!k_2,\ \dots,\ q_1\!\cdot\!k_T]$).
  3. Normalise with softmax: $\alpha_{ij}=\dfrac{\exp(e_{ij})}{\sum_{m=1}^{T}\exp(e_{im})}$, so $\sum_j\alpha_{ij}=1$.
  4. Mix the values: $z_i=\sum_{j=1}^{T}\alpha_{ij}\,v_j$.

11. Vectorized self-attention (all words at once)

11.1 Stack the inputs

Put the embeddings side by side as columns: $H=[h_1\ h_2\ \dots\ h_T]$, a $512\times T$ matrix. One matrix product projects every word simultaneously:

$$Q=W_QH,\qquad K=W_KH,\qquad V=W_VH\qquad\Rightarrow\quad Q,K,V\in\mathbb R^{64\times T}$$

Shape check: $(64\times512)(512\times T)=64\times T$. Column $j$ of $Q$ is $q_j$, and so on. The slide asks "$Q\in\mathbb R^{?}$" and answers $64\times T$.

11.2 All scores in one product

The entry in row $i$, column $j$ of $Q^TK$ equals $q_i^Tk_j$. So the full score table is one matrix product:

$$E=Q^TK\in\mathbb R^{T\times T}\qquad A=\text{softmax}_{\text{row}}\!\Big(\tfrac{E}{\sqrt{d_k}}\Big)\qquad Z=A\,V^T\in\mathbb R^{T\times d_v}$$ $$\boxed{Z=\text{softmax}\!\left(\frac{Q^TK}{\sqrt{d_k}}\right)V^T}$$

Row $i$ of $AV^T$ is $\sum_j A_{ij}v_j^T$, which is exactly $z_i=\sum_j\alpha_{ij}v_j$ from section 10. So the vector formula and the matrix formula are the same thing.

The whole layer is just matrix multiplications and a softmax, with no loop over words. That is the source of the Transformer's parallelism. The block is called a scaled dot-product attention head; its inputs come from $H$ through $W_Q,W_K,W_V$.

12. Why scale by $1/\sqrt{d_k}$? (full derivation)

12.1 Step 1: how large do dot products get?

Assume each component of $q$ and $k$ is an independent random number with mean 0 and variance 1. The dot product is a sum of $d_k$ products:

$$q\cdot k=\sum_{l=1}^{d_k}q_lk_l$$

Each term $q_lk_l$ has mean $0$ and variance $E[q_l^2]E[k_l^2]=1$. Variances of independent terms add, so

$$\text{Var}(q\cdot k)=d_k,\qquad \text{std}(q\cdot k)=\sqrt{d_k}$$

For $d_k=64$ the typical score has size about 8. For larger $d_k$ it is even bigger. Dividing by $\sqrt{d_k}$ gives $\text{Var}\big(\tfrac{q\cdot k}{\sqrt{d_k}}\big)=\tfrac{d_k}{d_k}=1$.

12.2 Step 2: why big scores are a problem

Softmax on big numbers becomes nearly one-hot: the largest score takes weight almost 1 and the rest almost 0. The derivative of softmax $\alpha_i=\dfrac{e^{e_i}}{\sum_m e^{e_m}}$ is

$$\frac{\partial\alpha_i}{\partial e_j}=\alpha_i(\delta_{ij}-\alpha_j)$$

If some $\alpha_i\to1$ then all other $\alpha_j\to0$, so every entry $\alpha_i(\delta_{ij}-\alpha_j)\to0$. The gradient vanishes, and the model can no longer learn to change which word it attends to.

Numeric feel ($d_k=64$)Two scores that differ by 8 (typical unscaled gap) give weight ratio $e^{8}\approx2981$: almost hard selection. After scaling the gap is about 1, ratio $e\approx2.7$: soft, trainable weights.

This is why the operation is named scaled dot-product attention: the scaling keeps the softmax input at unit variance for any $d_k$, giving stable gradient flow.

13. Multi-head attention

13.1 Motivation: the CNN analogy

Why does a CNN layer have many filters? Each filter learns a different pattern (edge, texture, shape); together they give richer abstract representations. Similarly, one attention head computes one weighted average per word, so it tends to focus on a single dominant relationship. We would like several different relationships at once. Solution: use several heads, each with its own $(W_Q^i,W_K^i,W_V^i)$, each computed independently and in parallel.

13.4 Dimensions ($d_{model}=512$, $h=8$)

  • Each head projects 512 → $d_k=d_v=512/8=64$ (so each head's $Q,K,V$ are $64\times T$, as in section 11).
  • Each head outputs $T\times64$. Concatenating 8 heads gives $T\times(8\cdot64)=T\times512$.
  • $W^O\in\mathbb R^{512\times512}$ mixes information across heads and returns the size to $d_{model}=512$, so layers can be stacked.
Why split 512 into 8×64?Total cost stays about the same as one 512-dimensional head, but you get 8 independent attention patterns. The heads are learned by training, not assigned by hand.

14. Position-wise feed-forward network (FFN)

After attention, each output vector $z_i$ (size 512) goes through a small two-layer neural network:

$$\text{FFN}(z)=\max(0,\ zW_1+b_1)\,W_2+b_2,\qquad 512\ \to\ 2048\ \to\ 512$$
  • Expand to 2048 numbers ($l=2048$ in the slide), apply the non-linearity (ReLU = max(0,·); the lecture summary also mentions GELU as a common choice), then project back to 512.
  • Position-wise: the identical network (same $W_1,b_1,W_2,b_2$) is applied to every position separately. In the slide FFN$_1$..FFN$_5$ are copies of one network applied to $z_1..z_5$ to give $o_1..o_5\in\mathbb R^{512}$.
  • Because each position is processed independently, this step is also fully parallel.
Division of labourAttention = communication between words (mixing information). FFN = computation within each word (adds non-linearity and capacity). Attention alone is only a weighted average (a linear mix of values), so the FFN is needed for richer transformations.

15.4 Where is it parallel and where is it not?

Horizontal direction (across the $T$ words, within a layer): fully parallelAll $z_1..z_T$ come from a few matrix products, and the FFN is applied to each position independently. No recurrence.
Vertical direction (across layers): sequentialLayer $l+1$ needs the complete output of layer $l$. But the depth is only 6, a small fixed number, whereas an RNN's sequential chain is as long as the sentence.

16.5 Practice questions

  1. Why is plain seq2seq limited? It squeezes the whole input into one vector and has no word alignment.
  2. Which parts of RNN-attention can be parallel? All $\alpha_{ti}$ for one step $t$; not across steps, because $s_{t-1}$ depends on earlier weights.
  3. Why do we need three matrices $W_Q,W_K,W_V$? Each word must act as a searcher, as something searchable and as a content carrier, and only one embedding is given.
  4. Shape of $Q^TK$ and of $Z$? $T\times T$ and $T\times64$ (per head).
  5. Why divide by $\sqrt{d_k}$? Dot-product variance is $d_k$; unscaled scores saturate softmax and make gradients vanish.
  6. Why multi-head? Different heads capture different relations (it → was, it → animal).
  7. What does $W^O$ do? Combines the concatenated heads ($8\times64=512$) back to 512-d.
  8. Is the encoder parallel across layers? No, only across positions; the 6 layers run one after another.
  9. How many parameters in the encoder? About 3M per layer, ≈18M for 6 layers.
